# 啊～啊～啊吧啊吧

用瀏覽器打開 `index.html`，把食材清單的 Excel 檔拖進去，就會算出每樣食材要叫多少。檔案只在瀏覽器裡處理，不會上傳。不需要網路。

## 檔案格式

每個工作表第一列要有「名稱」和需要量（「克」或「重量」）兩欄，有「備註」欄也會讀。一個檔案可以有多個工作表。

## 算法

- 重量、容量（g、kg、斤、ml）：叫貨量 = 需要量 ×（1 + 損耗率），無條件進位到整數。1 斤 = 600 克。
- 損耗率：備註裡寫了百分比就用那個數字；寫了兩個就算出範圍；沒寫用預設 5%。可在表格裡直接改。
- 按個數算的（顆、根、盒…）：不加損耗，只把小數進位。「片」照重量的算法。
- 雞蛋：進位後加 2 顆；備註寫「加 N 顆」就加 N 顆。

## Windows 桌面程式

同一個頁面用 Electron 包成免安裝的 Windows 程式，不需要網路。

```
npm install
npm start        # 在本機開啟視窗
npm run dist     # 產生 dist/啊～啊～啊吧啊吧.exe（Windows 64 位元，免安裝）
```

## Word 標準食譜

也可以拖入標準食譜的 Word 檔（.docx）。程式會讀出每道菜的「品名、數量」表格，把同一個檔案裡相同的食材加總成一個類別，並可下載「食譜整理 Excel」（食譜明細＋各檔案的食材合計）。數量照食譜原文加總，不依人份換算。

## 需要的材料 和 已叫貨的材料

程式會自動判斷每個檔案是哪一種：食譜和食材清單是「需要的」；檔名有「叫貨、日餐、材料單、送貨、已叫、刪」，或表格裡有「叫貨項目、送貨量」欄位的，是「已叫貨的」。合併總表顯示需要的量減掉已叫的量之後還要叫多少；已叫的量達到需要量 1.8 倍以上的，另外列在「連下次一起叫」。
