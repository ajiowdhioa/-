# 食材叫貨計算機

用瀏覽器打開 `index.html`，把食材清單的 Excel 檔拖進去，就會算出每樣食材要叫多少。檔案只在瀏覽器裡處理，不會上傳。第一次開啟需要網路（載入讀取 Excel 的元件）。

## 檔案格式

每個工作表第一列要有「名稱」和需要量（「克」或「重量」）兩欄，有「備註」欄也會讀。一個檔案可以有多個工作表。

## 算法

- 重量、容量（g、kg、斤、ml）：叫貨量 = 需要量 ×（1 + 損耗率），無條件進位到整數。1 斤 = 600 克。
- 損耗率：備註裡寫了百分比就用那個數字；寫了兩個就算出範圍；沒寫用預設 5%。可在表格裡直接改。
- 按個數算的（顆、根、盒…）：不加損耗，只把小數進位。「片」照重量的算法。
- 雞蛋：進位後加 2 顆；備註寫「加 N 顆」就加 N 顆。
